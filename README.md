## Hey, I'm Glaks 👋

This account is home to **OMINOY**, a Game Boy, Game Boy Color and Game Boy Advance emulator for Android.

### 🎮 About OMINOY

OMINOY runs on the mGBA libretro core, so it covers GB, GBC and GBA in one app. It's built to be simple and local-first: no cloud features, no account sync services, just your games and your saves on your device.

### ✨ Features

- **GB / GBC / GBA support** through the mGBA libretro core
- **RetroAchievements**
  - In-app login with a profile screen and logout
  - Clear error feedback when login fails
  - Per-account data separation, cleared on logout
  - Offline-first design: unlocks are saved locally and sync automatically once you're back online, even in a later session
- **Your files, your choice**: pick where saves are stored
- **Tidy storage**: achievement metadata and badge artwork are organised per game under one achievements folder

### 🚧 In progress

- Live in-game achievement tracking using rc_client
- Reading the mGBA memory map so achievements can be evaluated correctly
- Diagnostics logs written to a location you choose
